❌ Problem 1: Terraform "Invalid count argument" on Computed SNS Topic ARN
In modules/lambda/main.tf, evaluating count = var.custom_policy_json != null ? 1 : 0 failed during plan when custom_policy_json referenced module.s3_audit_sns.topic_arn because topic_arn is computed at apply time.
✔ Solution: Decoupled count from the policy string by introducing an explicit enable_custom_policy boolean parameter (count = var.enable_custom_policy ? 1 : 0).
❌ Problem 2: AWS CloudTrail vs. Native EventBridge Events
EC2 state notifications (Assignment 3) worked natively without CloudTrail, but S3 API modifications (Assignment 6) did not trigger EventBridge. In AWS, S3 control-plane API calls require an active AWS CloudTrail Trail (aws_cloudtrail) to stream events into EventBridge.
✔ Solution: Created CloudTrail trail dev-management-trail (aws cloudtrail create-trail & start-logging) to stream management API events to EventBridge.
❌ Problem 3: GitHub Actions PR Diffing Bug (PR #42)
On PR pushes, diffing github.event.before vs github.sha only checked consecutive commits on push, missing files modified earlier in the PR branch.
✔ Solution: Updated .github/workflows/lambda-ci-cd.yml for pull_request events to diff github.event.pull_request.base.sha vs github.event.pull_request.head.sha.
❌ Problem 4: Pytest Module Namespace Collisions
Standard pytest lambdas/*/test_handler.py cached sys.modules['handler'] from the first test suite, causing cross-suite test import failures.
✔ Solution: Configured dynamic module loading via importlib.util.spec_from_file_location in test files and updated Makefile to invoke pytest with --import-mode=importlib.
